# Notes — local/both-fixes

## Done

- Two independent fixes, each on its own branch, merged into `local/both-fixes`:
  1. **`fix/symlink-write-guard`** (`a52c8e8`) — `act --apply` and guard install/uninstall wrote edited config content back through `writeFile`, which follows symlinks. A cloned repo could commit `.claude/settings.json` (or `.mcp.json`, `CLAUDE.md`) as a symlink pointing outside the project, causing codeburn to silently overwrite an unrelated file (e.g. the user's global Claude Code settings). `runAction` now `lstat`s every edit/create target before mutating and refuses the whole plan if the target is a symlink.
  2. **`fix/sharing-sanitize-gap`** (`86f68a1`) — `sanitizeForSharing`'s own header comment promised project names, file paths, and per-session detail are never shared, but `pullRequests` (full `owner/repo#N` GitHub URLs), `byBranch` (git branch names), and top-level `claudeConfigs` (local filesystem paths, typically containing the OS username) were passing through untouched to any paired peer hitting `/api/usage`. Now stripped, matching the existing treatment of `topProjects`/`topSessions`.
